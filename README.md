# Marketing Tools

A collection of lightweight, browser-based tools for marketing measurement
and growth hacking. No backend, no build step, no dependencies — each tool
is a single HTML file that runs entirely client-side.

## Tools

### CAC vs LTV Calculator
`cac-ltv-calculator/index.html`

Customer acquisition cost against customer lifetime value, with the ratio
that tells you whether growth spend is actually paying off.

**What it does:**
- Calculates CAC, LTV, LTV:CAC ratio, payback period, and average customer
  lifespan from spend, new customers, ARPU, gross margin, and churn
- Visual gauge showing where the ratio sits against common health
  benchmarks (below 1:1 / 1–3:1 / 3–5:1 / above 5:1)
- Contextual guidance for each zone — what the number means, not just
  what it is
